# バージョニング

この API は URL パスでバージョンを管理します。

## 方式

- ベースパスは `/api/v1` とします。
- 後方互換性を壊す変更は新しいバージョンを追加して対応します。
- 既存バージョンのレスポンス形式や必須項目は、互換性を壊さない範囲で維持します。

## ルール

- 破壊的変更が必要な場合は `v2` を追加します。
- 新しいフィールドの追加は、既存クライアントに影響しない限り同一バージョンで行います。
- 削除予定の項目は、まず非推奨として明示します。

## 非推奨の扱い

- 非推奨の API は、可能な限りレスポンスやドキュメントで案内します。
- 代替 API がある場合は、移行先を明記します。
